# TowGo

A responsive roadside-assistance experience for drivers across Gauteng. Built with React, TypeScript and Vite, with a custom TowGo visual identity and locally bundled fonts.

## Run locally

```bash
npm install
npm run dev
```

The development server listens on `0.0.0.0:5173`.

## Production checks

```bash
npm run lint
npm run build
npm run preview
```

## Included flows

- Browse six roadside services with upfront prices and arrival estimates
- Request assistance through a validated three-step booking flow
- Use browser geolocation or enter pickup and destination addresses manually
- Confirm a request and follow a live operator view with trip sharing and cancellation
- Send messages to the assigned operator
- Check coverage by suburb or city
- Create a locally persisted TowGo profile and save vehicle details
- Responsive navigation, FAQs, fleet contact and 24/7 support links

This is a front-end product prototype. Live dispatch, payments, messaging and location updates are represented by local demo state and are ready to be connected to production services.
